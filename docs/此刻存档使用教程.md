# 此刻存档 · 新电脑使用教程

> 更新日期：2026-10-09
> 适用于：把项目搬到另一台电脑上继续改代码、发布上线。
> 先说结论：**只需要装一个 Node.js，再运行一条 `npm install`，就能用。** 项目里没有密码、密钥之类的配置文件。

---

## 0. 先弄清楚：搬走的是什么

| 东西 | 在哪里 | 换电脑会怎样 |
| --- | --- | --- |
| 项目代码和文档 | 电脑上的“此刻存档”文件夹 | 要拷到新电脑（本教程第 1 步） |
| 你的存档（文字、照片、语音） | **iPhone** 的浏览器里 | 不受影响，新电脑上看不到也不需要看 |
| 网站 https://cike-cundang.pages.dev | Cloudflare 的服务器上 | 不受影响，一直能打开 |
| 发布上线的登录状态 | 每台电脑自己身上 | 新电脑要登录一次（本教程第 5 步） |

所以换电脑**不会**影响 iPhone 上正在进行的 30 天验证。

---

## 1. 把项目拷到新电脑

### 1.1 拷贝前：在旧电脑上确认改动都已保存

在旧电脑的终端运行：

```bash
cd ~/Desktop/此刻存档
git status
```

看到 `nothing to commit, working tree clean` 就说明都保存好了。如果列出了文件，先让 AI 帮你提交（commit）再拷。

### 1.2 拷贝整个文件夹

用 U 盘、移动硬盘、网盘、隔空投送都可以，把**整个“此刻存档”文件夹**拷过去，建议放在新电脑的桌面上。

**一定要带上隐藏的 `.git` 文件夹**，里面是全部修改历史。确认方法：

- Mac：在“访达”里打开项目文件夹，按 `Command + Shift + .`（句号）显示隐藏文件，能看到 `.git` 就对了。
- Windows：文件资源管理器 →“查看”→ 勾选“隐藏的项目”。

**这两个文件夹可以不拷**（拷了也没关系，第 3 步会处理）：

- `node_modules`：依赖包，约 320 MB，新电脑上会重新下载；
- `dist`：打包结果，每次都会重新生成。

> 如果用压缩包传：Mac 右键文件夹 →“压缩”，会把 `.git` 一起压进去；Windows 上建议用 7-Zip，并确认压缩前已显示隐藏项目。

## 2. 在新电脑上安装 Node.js

Node.js 是运行这个项目唯一需要单独安装的工具。

1. 打开 https://nodejs.org ，下载 **LTS（长期支持）** 版本，版本号 **22 或更高**。
2. 双击安装包，一路“下一步 / 继续”装完。
3. 打开终端检查是否装好：
   - Mac：按 `Command + 空格`，输入“终端”打开；
   - Windows：开始菜单搜索“PowerShell”打开。
4. 输入下面两行，各回车一次：

   ```bash
   node -v
   npm -v
   ```

   第一行显示 `v22.x.x` 或更大的数字、第二行显示一个版本号，就是装好了。

**可选**：安装 Cursor（https://cursor.com ），用它打开项目文件夹，就能像现在这样让 AI 帮你改代码。

---

## 3. 下载依赖

在终端里进入项目文件夹。如果项目放在桌面上：

- Mac：

  ```bash
  cd ~/Desktop/此刻存档
  ```

- Windows（PowerShell）：

  ```powershell
  cd $HOME\Desktop\此刻存档
  ```

> 小技巧：先输入 `cd` 和一个空格，再把项目文件夹直接拖进终端窗口，路径会自动填好，然后回车。

如果你把旧电脑的 `node_modules` 也拷过来了，**先删掉它**（不同电脑之间不一定通用）：

- Mac：`rm -rf node_modules dist`
- Windows：`Remove-Item -Recurse -Force node_modules, dist`

然后下载依赖：

```bash
npm install
```

需要联网，等一两分钟。最后没有出现红色的 `ERR!` 就是成功了（出现黄色的 `WARN` 可以不管）。

---

## 4. 检查项目能不能正常运行

依次运行下面三条命令：

### 4.1 跑测试

```bash
npm test
```

最后显示 `Tests  95 passed (95)`（数字可能随以后的改动变化，关键是**没有 failed**）。

### 4.2 打包检查

```bash
npm run build
```

最后显示 `✓ built in ...` 就是成功。

### 4.3 在电脑浏览器里打开

```bash
npm run dev
```

终端会显示 `http://localhost:5173/`，在浏览器里打开它，能看到“存档”页面就成功了。

- 这是**本地开发版**，里面的存档和 iPhone 上的完全分开，随便存、随便删都不影响你的正式数据。
- 设置页最底下有“仅本地开发可见”的测试工具，可以一键生成 300 条测试存档或清空。
- 改代码后页面会自动刷新。
- 用完在终端按 `Control + C` 停止。

到这里，新电脑已经可以正常改代码了。

## 5. 发布上线（只有要更新网站时才需要）

改完代码、想让 iPhone 上的 App 也变成新版时，才需要这一步。

### 5.1 第一次：登录 Cloudflare

```bash
npx wrangler login
```

会自动打开浏览器，登录你的 Cloudflare 账号，点“Allow（允许）”。看到终端显示登录成功即可。**每台新电脑只需登录一次。**

### 5.2 发布

```bash
npm run deploy
```

最后显示 `✨ Deployment complete!` 就是发布成功。

注意：

- 终端里会显示一个带随机前缀的网址（例如 `https://e7e62c1f.cike-cundang.pages.dev`），那是**另一个仓库**，**不要在那里真实使用**。正式网址永远是 https://cike-cundang.pages.dev 。
- 发布前确认第 4 步的测试和打包都通过了。

### 5.3 让 iPhone 用上新版

1. 从主屏幕图标打开“此刻存档”；
2. 从屏幕底部上滑，把它从后台划掉；
3. 再从主屏幕图标打开。还是旧版的话，再划掉重开一次。

**不要**为了更新而删掉主屏幕图标——删图标会把里面的存档一起删掉。

## 6. 常见问题

| 遇到的情况 | 原因 | 怎么办 |
| --- | --- | --- |
| 输入 `node -v` 显示“command not found”或“无法识别” | Node.js 没装好，或装完没重开终端 | 关掉终端重新打开；还不行就重装 Node.js |
| `node -v` 显示的版本小于 22 | 版本太旧 | 到 nodejs.org 下载新版覆盖安装 |
| `npm install` 很慢或失败 | 网络问题 | 换个网络重试；还不行把报错截图发给 AI |
| `cd` 时提示找不到文件夹 | 项目没放在桌面，或名字不对 | 用“把文件夹拖进终端”的方法填路径 |
| `npm run dev` 提示端口被占用 | 已经开着一个 | 打开它显示的新地址即可，或关掉旧终端 |
| `npm run deploy` 提示没登录 / 没权限 | 这台电脑没登录 Cloudflare | 先做第 5.1 步 |
| 手机打开电脑的 `http://192.168.x.x` 不能录音 | 浏览器规定只有 https 才能用麦克风 | 手机上一律用正式网址测试（技术文档坑 3） |
| `git status` 提示“not a git repository” | 拷贝时漏了隐藏的 `.git` 文件夹 | 回到旧电脑，显示隐藏文件后重新拷 |

## 7. 让 AI 接手时，先让它读这些

在新电脑上用 Cursor 打开项目后，项目规则（`.cursor/rules/project.mdc`）会自动生效。开始改之前，可以先对 AI 说：

> 先读 docs 里的需求文档、技术文档、任务清单和版本总结，再开始改。这是纯前端项目，不要加后端。

各文档的作用：

| 文档 | 讲什么 |
| --- | --- |
| `此刻存档需求文档.md` | 要做什么、规则和文案 |
| `此刻存档技术文档.md` | 怎么实现的，以及 17 个容易踩的坑 |
| `此刻存档任务清单.md` | 每个任务和验收标准、当前进度 |
| `此刻存档版本总结.md` | 这一版做了什么、已知限制、改代码的注意事项 |
| `此刻存档使用教程.md` | 本文：换电脑怎么操作 |

## 8. 更省事的做法（可选）：放到网上的代码仓库

现在项目只存在电脑本地，换电脑要靠手动拷贝，旧电脑坏了代码也就没了。

可以把项目存到 Cursor 的代码仓库（不公开）：

- 换电脑时直接下载最新版，不用 U 盘拷来拷去；
- 每次提交后推送一下，就相当于多一份云端备份。

需要时对 AI 说“把项目保存到 Cursor 仓库”，它会帮你完成设置。设置好之后，新电脑的第 1 步就换成“下载仓库”，第 2～5 步不变。
